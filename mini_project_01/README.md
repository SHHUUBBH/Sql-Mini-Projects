# Mini Project 01: SQL Foundations & Database Operations

## Project Overview
This project demonstrates fundamental SQL and relational database operations, focusing on Data Definition Language (DDL), Data Manipulation Language (DML), data integrity constraints, schema evolution, and conditional data categorization.

## Skills & Concepts Covered
- **DDL & Schema Design:** Database creation, primary keys, auto-increment, unique constraints, check constraints, and foreign key relationships with cascading actions (`ON DELETE SET NULL`).
- **DML Operations:** Multi-row record insertions, targeted updates with mathematical calculations, and conditional record deletions.
- **Table Alterations:** Adding columns, renaming fields, and updating data type constraints using `ALTER TABLE`.
- **Filtering & Logic:** Multi-condition filtering (`WHERE`, `IN`, `BETWEEN`, logical operators).
- **Conditional Categorization:** Multi-tiered `CASE` statements to create business logic buckets for salaries, employee tenure, and performance ratings.
